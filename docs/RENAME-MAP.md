The word “hackathon” remains in copy that describes the product's use case. The `.hackathon/` project-state migration is documented separately because it concerns user data rather than the product name.

## Distribution behavior

Installers and package metadata expose the `sherpa` command. Uninstallers remove only Sherpa-managed global installation files and preserve project state. Release archives are generated by `scripts/build-release.py`; the release workflow publishes generated checksums and manifests.

The tracked `Microsoft/Windows/PowerShell/ModuleAnalysisCache` is an opaque PowerShell cache file, not an application resource. It remains outside release archives.
