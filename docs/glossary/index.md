# Glossary

| Term | Plain-language meaning |
|---|---|
| Adapter | Files that connect HackathonOS instructions to a particular AI agent host. |
| Artifact | A file produced or updated by a workflow. |
| Evidence | Project material that supports a report or claim. |
| Human approval gate | A point where a person must explicitly confirm a consequential choice. |
| Lifecycle phase | A recorded step in the project's progress, supported by project state and evidence. |
| Manifest | A structured file listing registered commands and their routing or runtime metadata. |
| Project state | HackathonOS records for one project, stored in `.hackathon/`. |
| Runtime verification | A test showing that the agent host actually discovers and invokes the integration. |
| Workflow | The procedure an operation follows, including its inputs, boundaries, and outputs. |
